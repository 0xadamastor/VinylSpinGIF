# Vinyl Mockup Generator

This is the Python script used to generate the animated vinyl GIF seen on my profile. It creates a realistic vinyl record mockup with a customizable label, center hole, and optional album cover overlay.

## Usage
1. **Install requirements:**
   - Python 3.x
   - Install dependencies with:
     ```bash
     pip install -r requirements.txt
     ```

2. **Run the app:**
   ```bash
   python app.py
   ```

3. **In the GUI:**
   - Use the default images or load your own vinyl template, cover, and label
   - Adjust label size and hole size as desired
   - (Optional) Enable GIF animation and set frame count/speed
   - Click "Generate Mockup" to create `mockup.png` (and `mockup.gif` if enabled)

4. **Output:**
   - `mockup.png`: Static vinyl mockup
   - `mockup.gif`: Animated spinning vinyl
   - `frames_png/`: Individual PNG frames for the animation
